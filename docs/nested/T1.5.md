# T1.5 — CPUID e CR0/CR4

## Cosa e' cambiato
- `sys/amd64/vmm/x86.c` (foglia CPUID 1): il bit `CPUID2_VMX` (ECX.5) viene
  mascherato SOLO se la capability nested e' spenta. Con `VM_CAP_NESTED_VIRT`
  attiva (vm_get_capability) l'L1 vede VMX in CPUID. EST/TM2/SMX restano mascherati.
- `sys/amd64/vmm/intel/vmx.c` `vmx_emulate_cr4_access`: CR4.VMXE dell'L1 e'
  tracciata nella read shadow (regval -> VMCS_CR4_SHADOW, gia' cosi'); in VMX
  operation (nested->vmxon) un MOV che azzera CR4.VMXE da' #GP e non si applica.
  La sincronizzazione LMA di vmx_emulate_cr0_access (d400b1ca3) resta invariata.

## Nota
L'applicazione piena dei bit CR4/CR0 "fixed" in VMX operation e' lasciata al
percorso di controllo di VMXON/ingresso (T1.7/T2.3). Qui c'e' il minimo per
test_vmxon: VMXE visibile e non azzerabile dopo VMXON.

## Collaudo
Compile: modulo vmm -Werror EXIT 0.
Hardware (Marietto): `test_vmxon` PASS (completa con T1.7). Con capability
spenta, CPUID.1.ECX.VMX resta 0 (R).
