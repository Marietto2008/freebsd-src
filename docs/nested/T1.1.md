# T1.1 — Costanti

## Cosa e' cambiato
- `sys/amd64/vmm/intel/vmx_controls.h`: `PROCBASED2_VMCS_SHADOWING (1 << 14)`
  dopo `PROCBASED2_ENABLE_INVPCID`.
- `sys/amd64/vmm/intel/vmcs.h`: encoding `VMCS_VMREAD_BITMAP 0x2026` e
  `VMCS_VMWRITE_BITMAP 0x2028` nel blocco dei 64-bit control fields.
- `sys/amd64/vmm/intel/vmx_nested.h` (NUOVO, derivato da ACRN -> header
  BSD-3 di Intel/ACRN conservato, mia riga di copyright sotto):
  `VMX_VMCS_SHADOW_BIT`, le MSR VMX 0x485/0x48A/0x491 (guardate con #ifndef),
  i codici d'errore VMX (VMXERR_*, SDM), `VMX_NESTED_MAX_VMCS12`.

## Come si collauda (Claude Code)
- `vmx_nested.h` ancora non e' incluso da nessuno (lo includera' T1.3):
  verificato standalone con `cc -fsyntax-only -x c vmx_nested.h` -> OK.
- Le due aggiunte a vmx_controls.h/vmcs.h sono compilate dal modulo vmm
  (le includono vmx.c e vmcs.c): `make -C sys/modules/vmm KERNBUILDDIR=...`
  deve restare verde, senza nuovi warning. Nessun campo rinominato o rimosso.

## Quali log servono
Nessuno sull'hardware: T1.1 non cambia comportamento a runtime (solo #define,
di cui VMCS_SHADOWING non ancora usato). La regressione R non e' toccata.
