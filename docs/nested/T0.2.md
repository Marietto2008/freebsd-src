# T0.2 — build.sh e nested.env.example

## Cosa c'e'
- `tools/nested/build.sh`: build di modulo vmm (vmm-restore.ko + .debug),
  libvmmapi/bhyve/bhyvectl e accel QEMU, con STAGING in `$STAGE`. Nessun
  install di sistema, nessun kldload, nessun avvio VM (§3).
- `tools/nested/nested.env.example`: SRC, QEMU_SRC, KERNCONF, KERNBUILDDIR,
  MAKEOBJDIRPREFIX, STAGE, TEST_CPUS. Copiare in `nested.env` (non committato).
- `tools/nested/f0-vmxcaps.sh`: lo script F0 (lo lancia Marietto).

## Come si collauda (Claude Code)
    cp tools/nested/nested.env.example tools/nested/nested.env   # gia' adatto al workspace
    sh tools/nested/build.sh --prova    # mostra la sequenza, non costruisce
    sh tools/nested/build.sh            # build completa -> $STAGE/<id> + MANIFEST + current

Fatto quando: da albero pulito `build.sh` produce `$STAGE/<id>` con
vmm-restore.ko(.debug), lib/libvmmapi.so*, sbin/bhyve, sbin/bhyvectl,
bin/qemu-system-x86_64, include/ e MANIFEST, e non scrive fuori da `$STAGE`
e dalle obj dir.

## Note
- `build.sh` si FERMA se manca `$QEMU_SRC/target/arm/bhyve/meson.build`
  (§0.3): sul clone di ottobre quel file c'e' (aggiunto in add5fe45), quindi
  la verifica di T0.2 passa.
- KERNBUILDDIR di default punta all'obj del kernel VMMSNOOP gia' costruito da
  /usr/src: va bene per il compile-check. Per una build fedele si fa prima
  `make -C $SRC buildkernel KERNCONF=VMMSNOOP` e si punta l'obj del clone.
- Build reale VERIFICATA VERDE (build-id 20261016-134719): $STAGE/current ha
  vmm-restore.ko, libvmmapi.so.7, bhyve, bhyvectl, qemu-system-x86_64 (con
  l'accel bhyve dentro) e MANIFEST.
- Lezioni di piattaforma FreeBSD (gia' dentro build.sh):
  * gli obj userland stanno sotto `$MAKEOBJDIRPREFIX$SRC/amd64.amd64/...`,
    quelli del modulo sotto `.../amd64.amd64/sys/modules/vmm`; il modulo si
    chiama `vmm-restore.ko` (non vmm.ko), §0.4.7;
  * QEMU va configurato con `--enable-bhyve --extra-cflags=-I/usr/local/include
    --extra-ldflags=-L/usr/local/lib` (libinotify sta in /usr/local/lib),
    tenendo PRIMA i path di $STAGE per la nostra libvmmapi;
  * il Makefile di QEMU e' GNU: si compila con `gmake`, non con make(1) di BSD.
