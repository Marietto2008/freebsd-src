# T1.3 — Stato nested e file nuovi

## Cosa c'e'
- `sys/amd64/vmm/intel/vmx_nested.h`: `struct vmx_nested` (vmxon, in_l2,
  init_pending, vmxon_ptr, current_vmcs12, cache[4] VMCS12->VMCS02, vmx_msr[18]
  + feature_control per T1.4, msr_bitmap fusa per T6.3) e `struct vmcs12_cache`;
  `MALLOC_DECLARE(M_VMX_NESTED)`; prototipi `vmx_nested_init/free`.
- `sys/amd64/vmm/intel/vmx_nested.c` (NUOVO, ACRN BSD-3): `MALLOC_DEFINE`,
  le probe SDT `vmm:vmx:nested:*` (enter_l2, reflect, synth_exit, slowpath,
  shadow_fill, vmfail, init_latched), i contatori `VMM_STAT_INTEL`, e il ciclo
  di vita:
  * `vmx_nested_init(vcpu)`: alloca `struct vmx_nested` (M_WAITOK|M_ZERO),
    current_vmcs12 e le voci di cache = VMCS12_GPA_NONE. msr_bitmap e le pagine
    VMCS02 restano NULL (alloc pigra in T6.3 / T1.8). Idempotente.
  * `vmx_nested_free(vcpu)`: libera pagine VMCS02, msr_bitmap e la struct;
    azzera il puntatore. Idempotente.
- `sys/amd64/vmm/intel/vmx.h`: forward-decl `struct vmx_nested` e campo
  `struct vmx_nested *nested` in `struct vmx_vcpu`.
- `sys/modules/vmm/Makefile`: `vmx_nested.c` in SRCS (dopo vmx.c).
- `sys/amd64/vmm/intel/vmx.c`: include vmx_nested.h; in `vmx_setcap` il caso
  NESTED_VIRT ora alloca (0->1) / libera (1->0) lo stato; `vmx_vcpu_cleanup`
  chiama `vmx_nested_free`.

## Collaudo
Compile: modulo vmm ricostruito -Werror (VMMSNOOP), vmx_nested.o linkato in
vmm-restore.ko. EXIT 0, zero warning.
Sull'hardware (Marietto): `vmstat -m | grep vmx` deve essere uguale prima e
dopo 20 cicli create/destroy con capability=1 (niente leak: init/free bilanciati;
M_VMX_NESTED separato rende il conteggio verificabile a parte).
