# T1.4 — MSR VMX e FEATURE_CONTROL esposti all'L1 (D4 = C + D4.b)

## Cosa c'e'
- `vmx_nested.c` `vmx_nested_init_msrs()` (chiamata da vmx_nested_init):
  calcola `vmx_msr[0x480..0x490]` e `feature_control` DALL'HOST:
  * BASIC: revisione dell'host, dimensione 4096, memtype WB, bit 54 (INS/OUTS)
    e 55 (true controls);
  * pin-based (0x481/0x48D): host + ext-int(0) e NMI(3) exiting **must-be-1**
    nelle allowed-0 (D4.b);
  * proc-based/exit/entry (0x482/3/4 e true 0x48E/F/490): come l'host;
  * MISC (0x485): host senza PT, SMBASE, VMXOFF-SMI e rate del preemption timer;
    bit 29 (VMWRITE-any) mantenuto (F0 = SI → variante a);
  * CR0/CR4 FIXED e VMCS_ENUM: dall'host;
  * proc-based2 (0x48B): host MENO le feature escluse di §6.3 (APIC virt, VMFUNC,
    VMCS shadowing per l'L1, PML, ENCLS/ENCLV, #VE, XSAVES, MBEC, SPP, PT, TSC
    scaling), tolte dalle allowed-1;
  * EPT/VPID cap (0x48C): host senza EPT A/D e page-walk a 5 livelli;
  * FEATURE_CONTROL (0x3A): LOCK | VMX-outside-SMX.
- `vmx_msr.c`:
  * `vmx_rdmsr`: 0x3A e 0x480..0x490 → dal nested quando la capability e'
    attiva (vcpu->nested != NULL); 0x491 (VMFUNC) → #GP. Nested spento →
    EINVAL come prima (0x3A continua ad andare a userland/xmsr: R intatta).
  * `vmx_wrmsr`: 0x3A e 0x480..0x491 → #GP quando il nested e' attivo (MSR di
    capability in sola lettura, FEATURE_CONTROL bloccata da LOCK); altrimenti
    EINVAL come prima.

## ⚠ Il set di bit e' PROVVISORIO
Derivato dall'host con le esclusioni/forzature del piano, ma il set esatto lo
conferma `test_vmx_caps` di kvm-unit-tests SULL'HARDWARE (criterio di T1.4).
Se quel test segnala bit incoerenti, si rifinisce `vmx_nested_init_msrs()`.
I valori grezzi dell'host sono in `docs/nested/f0-vmxcaps.txt`.

## Collaudo
Compile: modulo vmm -Werror EXIT 0.
Hardware (Marietto): `test_vmx_caps` e `test_vmx_feature_control` PASS; con la
capability spenta, `rdmsr 0x3a` nel guest invariato (R).
